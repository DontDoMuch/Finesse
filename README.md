# Finesse

**Finesse makes it easy to install newer AMD graphics drivers unofficially** on these Lenovo handhelds:

- **Legion Go 1** — Z1 Extreme
- **Legion Go S** — Z1 Extreme *(physical testing in progress)*
- **Legion Go 2** — Z2 Extreme

## Installation

1. Install the [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vc14/vc_redist.x64.exe).
2. Download **Finesse.exe** from the [Releases page](https://github.com/DontDoMuch/Finesse/releases).
3. Run **Finesse.exe** and follow the on-screen instructions.

*Finesse is an independent, unofficial project and is not affiliated with Lenovo or AMD.*
