# Instructions

**Finesse** makes it easy to install newer AMD graphics drivers unofficially on supported Lenovo handhelds.

1. **Use a supported handheld running Windows 11 (any edition):** Legion Go 1 (Z1 Extreme), Legion Go S (Z1 Extreme), or Legion Go 2 (Z2 Extreme).
2. **Install the prerequisite:** [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vc14/vc_redist.x64.exe).
3. **Install Finesse:** Download **Finesse.exe** from [Releases](https://github.com/DontDoMuch/Finesse/releases), run it, and follow the on-screen instructions.
4. Expect about 10 minutes for the install and a one time reboot

## Windows Security

Windows or antivirus software may show a warning or block when running Finesse. Some warnings may be false positives, but a warning alone does not establish that the file is safe. Download only from the official repository and verify available release information.

If you downloaded **Finesse.exe** from our [Releases](https://github.com/DontDoMuch/Finesse/releases) and Windows blocks it from running, try to **Unblock** it by right-click the file → **Properties** → **General** → check **Unblock** → **Apply** → **OK**, then try again.

**Don't disable your antivirus.** If it detects or quarantines a specific threat, ask for help in our Discord before proceeding.
